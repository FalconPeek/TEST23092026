# T-027 worker report

## Summary
- `messages/es.ts`: added `match.unattributed(n)`, `amendTitle`, `amendHelp`, `amendSave`,
  `amended`, `amendOverScore(team)`.
- `lib/match/amend.ts` (+ test): pure helpers mirroring `amend_match_stats`'s SQL exactly:
  - `unattributedGoals(score, stats)`: per side, `score − Σ goals(side) − Σ own_goals(opponent)`,
    clamped at 0.
  - `validateAmendment(score, stats)`: per side, flags `goals(side) + own_goals(opponent) > score`
    or `assists(side) > score − own_goals(opponent)` — the same two caps the RPC re-checks after
    applying the amendment.
  - `changedRows(initial, edited)`: only rows with at least one changed field, and only the
    changed keys within them (matches `amend_match_stats`' "only the keys present are changed").
  10 tests covering all three.
- `components/match/match-result.tsx` (+ test): under each team's stats table, when
  `unattributedGoals` is > 0 for that side, shows a muted `"N goles sin autor"` line next to the
  team name heading. Added 2 tests (shows it when the score doesn't fully add up; doesn't show it
  when every goal is attributed) alongside the existing 3, which still pass unchanged.
- `components/match/amend-stats-form.tsx` (+ test): `'use client'`. A `<details>`/`<summary>`
  "Asignar goles" section (same collapsible pattern as `GroupSettingsForm`'s "Avanzado" and
  `CreateTournamentForm`'s "Reglas"), one `PlayerStatRow` per team player (reusing T-015's
  `stat-row.tsx`, so every stepper is already ≥44px) prefilled from `match_stats`, a live
  per-team `"N goles sin autor"` counter, and `amendOverScore` shown + submit disabled while a
  side is over its cap. Submit sends only `changedRows(initial, edited)` to `amendMatchStats`,
  toasts `match.amended`, and `router.refresh()`s. No admin prop on the component itself — the
  page decides whether to render it at all, matching the task's note that non-admin hiding is a
  page-level concern. 4 tests: only-changed-field payload, blocked+error over the cap, the live
  counter, and save disabled with nothing changed yet.
- `app/g/[groupId]/partidos/[matchId]/page.tsx`: built `amendPlayers` (team1+team2 players with
  side) and `amendInitialStats` (from the already-fetched `matchStatsRows`) alongside the existing
  `matchResultStats`, and render `AmendStatsForm` right after `MatchResult` when
  `match.status === "finalized" && admin`, passing the score from `matchResultRow`.
