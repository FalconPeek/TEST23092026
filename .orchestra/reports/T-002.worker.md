# T-002 worker report

## Summary
Dark pitch-at-night theme, FUT tier color tokens, `.fut-shield` clip-path utility, root
layout (es-AR, metadata, viewport, ThemeProvider + Toaster), and a mobile-first landing
page — all copy sourced from `messages/es.ts`.

## Files changed
- `app/globals.css` — reworked `.dark` palette (near-black green-tinted background,
  vivid pitch-green primary `oklch(0.72 0.19 150)` with dark foreground on primary,
  accent/ring tuned to match); added 20 tier CSS vars (`--tier-<bronze|silver|gold|special|provisional>-<from|to|fg|accent>`)
  defined once in `:root` (theme-independent) and exposed in `@theme inline` as
  `--color-tier-*` so Tailwind utilities like `bg-tier-gold-from`, `text-tier-gold-fg`,
  `border-tier-gold-accent` work; added `@utility fut-shield` (7-point clip-path polygon:
  flat top with cut corners, tapered point at the bottom).
- `app/layout.tsx` — `lang="es-AR"`, `className="dark ..."`, `suppressHydrationWarning`;
  `metadata` with title template `%s · Picado`, description from `es.app.tagline`,
  `applicationName`; `viewport` export (`themeColor` matching the dark background,
  `width`/`initialScale`/`viewportFit`); wraps children in `ThemeProvider` and renders
  `<Toaster position="top-center" richColors />`; body uses `min-h-dvh bg-background
  text-foreground` plus `env(safe-area-inset-*)` padding via Tailwind arbitrary values.
- `app/page.tsx` — replaced the create-next-app boilerplate with a Server Component
  landing page: hero (app name, tagline, CTA `Button asChild` → `Link href="/login"`,
  label from `es.landing.cta`), and a 2-column card grid rendering `es.landing.features`
  with lucide icons (`CreditCard`, `Trophy`, `BarChart3`, `Star`). All copy from
  `messages/es.ts`.
- `components/theme-provider.tsx` (new) — thin client wrapper around `next-themes`'
  `ThemeProvider` with `attribute="class"`, `defaultTheme="dark"`, `enableSystem={false}`,
  needed because `components/ui/sonner.tsx` calls `useTheme()`.
