# T-006 worker report

## Summary
Built the app shell (top bar + bottom nav), the `/g` "my groups" list with a create-group
dialog, the `/g/[groupId]` layout + group home, and placeholder pages for
partidos/torneos/rankings so bottom-nav links don't 404. Signed-in users hitting `/` are
now redirected to `/g`.

## Known issues / assumptions
- `es.groups.members(n)` count on `/g` and the group home uses active `players`
  (`left_at is null`), not `group_members` row count — matches the data model note that
  every member (incl. spectators) has a `players` row, and matches the member-avatar
  preview's own filter, so the two "N miembros" labels on a group page agree.
- `nav.groups` is used as the sr-only label on the group-layout's back button, not as a
  visible nav-bar caption — no other natural spot for it existed given the task's other
  Spanish-copy keys were already pinned to specific UI spots.
- Non-uuid group ids and RLS-hidden groups both fall through to the same `notFound()` in
  the layout (no leak — no distinction is made between "doesn't exist" and "not yours").
