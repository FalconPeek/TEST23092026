## Notes / deviations from the literal spec text
- `formatDateLong` / `formatDateTime`: actual `Intl.DateTimeFormat("es-AR", { weekday: "long", day: "numeric", month: "long" })`
  output includes a comma after the weekday (e.g. "miércoles, 23 de septiembre"), not
  "miércoles 23 de septiembre" as the task text suggested. Kept the real ICU output and
  adjusted the test expectation to match — didn't hand-strip the comma since that would
  diverge from standard es-AR formatting.
- `formatRelative` for sub-minute diffs: spec says "seconds < 60 → minutes", i.e. the smallest
  unit ever shown is minutes (never seconds). Implemented as: for |diff| < 1 minute, format
  with unit "minute" and value 0. Real ICU output for `RelativeTimeFormat("es-AR", {numeric:"auto"}).format(0, "minute")`
  is "este minuto", not "ahora" — used the real string in the test.
- All other helpers matched the spec's example outputs exactly (formatDate "23/9/2026",
  formatTime "22:30", formatNumber "1.234", formatDecimal "7,5", formatPercent "40 %"-style,
  "ayer"/"mañana"/"pasado mañana" for ±1/±2 days, hour/minute relative phrasing).
- `es` has exactly 29 outfield + 5 GK = 34 attribute keys and 15 position keys, verified by a
  dedicated test per acceptance criteria.
