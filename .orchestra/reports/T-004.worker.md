  `CardTier`, `PositionCode`, `OutfieldFace`, `GkFace`, `PlayStyleBadge`, `PlayerCardProps`

## Production 404 verification
- Inspected the build output directly: `.next/server/app/dev/cards.html` contains "404"
  and does **not** contain the gallery content ("Player card preview") — confirms
  `notFound()` fired during static generation (Next builds with `NODE_ENV=production`,
  same as `next build`/`next start`), so the page is baked as the not-found shell before
  it ever ships.
- Also ran `npm run start` and curled `/dev/cards` → got a `307` redirect, **not** a
  `404`. This is `proxy.ts`'s auth gate (`lib/supabase/proxy.ts` `PUBLIC_PATHS`) acting
  first and unconditionally redirecting unauthenticated requests to `/login`, since
  `/dev/cards` isn't in that public-paths list — it never even reaches the page component.
  This is a second, independent layer of protection on top of the `notFound()` guard, not
  a conflict; both together mean `/dev/cards` is unreachable in production either way. Not
  changing `proxy.ts` since it's outside this task's Files.
