## Notes for Verifier

- Crest cache-busting: `club-form.tsx` appends `?v=${Date.now()}` after a client upload so the preview updates immediately. The server-rendered detail/list pages use the bare `getPublicUrl(...).data.publicUrl` (no `?v=`) since there's no `updated_at` on `clubs` to derive a stable cache-busting key from; this only affects browser/CDN image caching after a crest change until the page's own cache or the image URL otherwise changes, not correctness.
- `club-form.test.tsx`'s SVG-rejection test needed `userEvent.setup({ applyAccept: false })` — by default `userEvent.upload()` filters files against the input's `accept` attribute before firing `change`, so a real accept-mismatched file never reaches the component's own validation in a default `userEvent` setup. This bypass is intentional: it exercises the component's own defense-in-depth check (a user could still get a wrong-type file past the OS picker via drag-and-drop).
