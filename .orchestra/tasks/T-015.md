## Context
The finalizer runs server-side:
- it reconciles score/stat reports (`lib/reconcile`, Rule A in CLAUDE.md);
- writes `match_results(match_id, team1_goals, team2_goals, pens1, pens2, decided_by, winner_side)` and `match_stats(match_id, player_id, goals, assists, own_goals, saves, clean_sheet, is_mvp, median_rating)`;
- updates OpenSkill and cards;
- sets `finalized`, or `disputed` when the score reports disagree / stats can't be reconciled.

Admins resolve a dispute with `resolveDispute({ groupId, matchId, team1Goals, team2Goals, stats? })` from `lib/actions/matches.ts`. That moves the match to `pending_finalize` and logs to `match_audit`.

FATHER provides `finalizeMatchNow({ matchId })` in `lib/actions/finalize.ts` (admin: closes the windows early and runs the finalizer immediately; returns `ActionResult`). Read that file before starting. If it doesn't exist yet, set this task back to `todo`, stop, and note it in your report.
