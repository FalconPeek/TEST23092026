## Context
Each group member has a `players` row. The server recompute pipeline writes these derived tables, which members can select (RLS already scopes them to the group):
- `player_cards(player_id, ovr, position, tier bronze|silver|gold|special, is_provisional, face jsonb, ovr_by_position jsonb, weak_foot, skill_moves, playstyles jsonb, n_raters, updated_at)`.
  - `face` is either `{pac,sho,pas,dri,def,phy}` (outfield) or `{div,han,kic,ref,pos,spd}` (GK).
  - `playstyles` is `[{ code, plus }]`.
  - A player with no votes yet has **no row**.
- `attribute_ratings(player_id, attribute, value 1–99, n_votes, n_raters, updated_at)`.
- `match_stats(match_id, player_id, goals, assists, own_goals, saves, clean_sheet, is_mvp, median_rating)`, but only for finalized matches.

`components/card/player-card.tsx` (T-004) renders the FUT card from `PlayerCardProps`. Face-stat → sub-attribute mapping: `FACE_STAT_WEIGHTS` / `subAttributesOfFaceStat` in `lib/rating/attributes.ts`. Playstyle codes: `lib/rating/playstyles.ts` (T-010). Recharts 3 plus the shadcn `components/ui/chart.tsx` wrapper are installed. Next 16: `params` is a Promise.

## Steps
1. `lib/cards/to-card-props.ts` (new, pure): `toCardProps(player, cardRow | null, labels) → PlayerCardProps | null`.
   - Validate the jsonb with zod (`face` as either shape; `playstyles` array). Clamp stars to 1–5 (default 3 when null).
   - Label playstyles via `es.playstyles[code]`, with `plus` kept.
   - Return null when there's no card row.
   - Colocated test: outfield, GK, missing row, malformed jsonb → null, and null stars → 3.
2. `messages/es.ts`:
   - `playstyles`: Spanish labels for all 30 codes. Use FC 26 Spanish names where they exist, e.g. finesse_shot "Tiro colocado", power_shot "Tiro potente", dead_ball "Balón parado", chip_shot "Vaselina", incisive_pass "Pase incisivo", pinged_pass "Pase tenso", long_ball_pass "Pase largo", tiki_taka "Tiki-taka", whipped_pass "Centro con rosca", first_touch "Primer toque", rapid "Rápido", flair "Talento", press_proven "Resiste presión", technical "Técnico", trickster "Pícaro", intercept "Intercepción", anticipate "Anticipación", block "Bloqueo", bruiser "Fortachón", jockey "Jockey", slide_tackle "Barrida", aerial "Aéreo", relentless "Incansable", quick_step "Paso rápido", acrobatic "Acrobático", far_reach "Gran alcance", footwork "Juego de pies", cross_claimer "Dominio de centros", rush_out "Salida rápida", deflector "Desviador".
   - `profile`: `noCard` ("Todavía no tiene votos suficientes para su carta."), `raters` `(n) => …` ("Votado por 1 compañero"/"n compañeros"), `attributes` "Atributos", `stats` "Estadísticas", `matches` "Partidos", `goals` "Goles", `assists` "Asistencias", `mvps` "Figura", `cleanSheets` "Vallas invictas", `avgRating` "Puntaje promedio", `vote` "Votar", `editProfile` "Editar perfil", `positionOvr` "Media por posición".
3. `components/charts/face-stats-radar.tsx` (`'use client'`): a Recharts RadarChart of the 6 face stats (0–99 domain). Labels come from `es.card.faceStats`/`gkStats`, colored with the tier CSS tokens. It must be accessible: also render an `sr-only` list of values.
4. `components/player/attribute-list.tsx` (server-safe): attributes grouped under their face stat (6 groups; GK players get a 7th "Arquero" group with the `gk_*` attributes). Each row shows the label (`es.attributes`), the value with a colored bar (<50 red, <65 amber, <75 lime, else green, using tokens), and n_raters muted.
5. `app/g/[groupId]/jugadores/[playerId]/page.tsx` (Server Component):
   - Load the player (`notFound()` if not visible or the group doesn't match), the card row, attribute_ratings, and aggregates from match_stats (matches played, goals, assists, MVPs, clean sheets, average median_rating).
   - Layout: card (size lg, centered) with the raters count and provisional hint; a "Votar" button → `/g/[id]/jugadores/[pid]/votar` (hidden on my own player); an "Editar perfil" link when it's my player (existing `/editar` route from T-009).
   - Then the radar, a stat tiles row, a top-5 "Media por posición" chips row from `ovr_by_position`, and the attribute list.
   - Empty states when there's no card or no stats.
6. Link players to their profile: in the group home members preview (`app/g/[groupId]/page.tsx`), make each avatar link to `/g/[id]/jugadores/[pid]`.
7. Tests: `lib/cards/to-card-props.test.ts`, and `components/player/attribute-list.test.tsx` (grouping, GK group only for GK, bar color thresholds).
