## Context
RPC `get_my_dashboard(p_group_id)` returns jsonb:
```
{ player_id, ovr_history: [{ snapshot_at, ovr }] (oldest first), recent_matches: [...] (last 10, newest first),
  totals: { matches_played, goals, assists, own_goals, saves, clean_sheets, mvps }, impacto: number|null,
  card: player_cards row minus player_id | null, badges: [{ badge_code, awarded_at, count }] }
```
It raises `PICADO_NOT_MEMBER` if I have no active player in that group. Read the migration `supabase/migrations/20260923211743_dashboard_rpcs.sql` for the exact `recent_matches` item shape.

The top bar user menu (T-006) already links to `/yo`. A user can belong to several groups.

Reuse existing pieces: `PlayerCard` + `toCardProps` (`lib/cards/to-card-props.ts`), `BadgeList` (T-023), `FaceStatsRadar` (T-011), and Recharts via `components/ui/chart.tsx`.

## Steps

   - `title` "Mi progreso", `pickGroup` "Grupo", `noGroups` "Sumate a un grupo para ver tu progreso.", `ovrHistory` "Evolución de tu media", `recentMatches` "Últimos partidos", `totals` "Totales", `impacto` "Impacto", `noHistory` "Todavía no hay historial.";

2. Zod schema `lib/dashboard/schema.ts` to parse the RPC jsonb (never trust the shape), with a test.
3. `app/yo/page.tsx` (RSC, signed-in only; `proxy.ts` already protects it):
   - List my groups. `?group=` is validated as one of my groups, defaulting to the first.
   - Show a group switcher (links) when there's more than one.
   - Call `get_my_dashboard`. Render: the card (md) with the impacto next to it; an OVR line chart (`components/charts/ovr-history-chart.tsx`, `'use client'`, Recharts LineChart, dates via `lib/format.ts`, with the empty state when there are <2 points); totals tiles; recent matches (date, score, W/D/L chip, my G/A, MVP star, link to the match); and the badges.
   - Wrap it in the app-shell top bar; there's no group bottom nav here, so add a simple back link to `/g`.
4. Tests: `lib/dashboard/schema.test.ts` (valid, missing fields → safe defaults or a rejection, as you choose and document) and `components/charts/ovr-history-chart.test.tsx` (the empty state).
