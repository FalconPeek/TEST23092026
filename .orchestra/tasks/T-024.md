## Context
RPC `get_group_leaderboard(p_group_id, p_metric, p_limit default 20)` returns `[{ player_id, display_name, avatar_url, value numeric, rank int, matches_played int }]`.
- Metrics: `ovr | impacto | goals | assists | mvps | clean_sheets | avg_rating | matches`.
- Ties share a rank.
- Players who left are excluded.
- `avg_rating` requires ≥3 rated matches.
- It raises `PICADO_NOT_MEMBER` for non-members.

"Impacto" is the OpenSkill ordinal mapped to a 1–99 percentile within the group. The T-006 placeholder `app/g/[groupId]/rankings/page.tsx` gets replaced. Read it in the RSC with the session client (`supabase.rpc`); no client fetching is needed.

## Steps
1. `messages/es.ts`: add `rankings.*`:
   - `title` "Rankings";
   - `metrics.{ovr "Media", impacto "Impacto", goals "Goles", assists "Asistencias", mvps "Figuras", clean_sheets "Vallas invictas", avg_rating "Puntaje promedio", matches "Partidos"}`;
   - `impactoHelp` "Impacto mide cuánto influís en que tu equipo gane (1 a 99, relativo al grupo).", `avgRatingHelp` "Mínimo 3 partidos puntuados.", `empty` "Todavía no hay datos para este ranking.", `matchesPlayed` `(n) => …`, `you` "Vos".
2. `app/g/[groupId]/rankings/page.tsx`:
   - `searchParams.metric` is validated against the 8 metrics (default `ovr`).
   - A horizontally scrollable metric chip bar (links with `?metric=`).
   - A podium for the top 3 (avatar, name, value; 1st in the middle and larger).
   - Then a list for rank 4+ (rank, avatar, name, value, matches played muted). My own row is highlighted with "Vos" (compare `player_id` with my player in the group).
   - Format values: `avg_rating` with 1 decimal, the others as integers.
   - Help text below for `impacto` and `avg_rating`.
3. `components/rankings/podium.tsx` and `components/rankings/leaderboard-list.tsx` (server-safe). Each player links to `/g/[id]/jugadores/[playerId]`.
4. Pure helper `lib/rankings/format.ts` (`parseMetric`, `formatMetricValue`, `splitPodium`) with tests, including ties in the top 3.
5. Tests: `lib/rankings/format.test.ts`, `components/rankings/podium.test.tsx`.
