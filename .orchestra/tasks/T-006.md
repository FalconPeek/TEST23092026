## Context
Signed-in users live under `/g` (group list) and `/g/[groupId]/…` (group-scoped pages). `proxy.ts` already redirects unauthenticated users to `/login?next=…` for everything except `/`, `/login`, `/auth/*`, `/invitacion/*`. Reads happen in Server Components via `createClient()` from `lib/supabase/server.ts` (RLS scopes them to the user's groups). Writes via `lib/actions/groups.ts` (T-005). Tables available: `groups(id,name,slug,owner_id,settings,created_at)`, `group_members(group_id,user_id,role,joined_at)`, `players(id,group_id,user_id,display_name,avatar_url,is_guest,left_at,primary_position,…)`, `profiles(id,display_name,avatar_url)`. Next 16: `params` is a Promise. Read `node_modules/next/dist/docs/` for layouts/`notFound`/`redirect`.
