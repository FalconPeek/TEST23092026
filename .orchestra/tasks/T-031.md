## Context
Admins can build a scheduled match's lineup visually. Each side is a `lineup` squad:
- save it with `saveSquad({ squadId|null, groupId, kind: "lineup", name, teamSize: match.team_size, formation, slots, clubId|null, matchId, side: 1|2 })`;
- the RPC allows admins only and scheduled matches only, with one squad per side.

`applyLineupSquads({ groupId, matchId })` (`lib/actions/squads.ts`) then writes the real lineup via `set_match_lineup`. Players keep their slot position, and the team name and color come from the club when one is set. The existing list editor (`components/match/lineup-editor.tsx`, T-013) stays as the "Lista" mode. Reuse `SquadEditor`/`Pitch` from T-030 and `ClubCrest` from T-029.

## Steps
1. `messages/es.ts`: add `matches.lineupModeList` "Lista", `matches.lineupModePitch` "Cancha", `matches.applyLineup` "Usar estas alineaciones", `matches.applyLineupConfirm` "Se reemplazan los equipos del partido por las dos alineaciones de la cancha.", `matches.lineupApplied` "Alineaciones aplicadas", `matches.pickClub` "Club (opcional)", `matches.needBothSides` "Armá las dos alineaciones primero.".
2. `app/g/[groupId]/partidos/[matchId]/equipos/page.tsx`: a Lista/Cancha segmented toggle (`?modo=cancha`).
   - Cancha shows two `SquadEditor`s (Equipo 1 / Equipo 2) in `kind="lineup"` mode, with a fixed team size and prefilled from the existing lineup squads.
   - A player placed on one side is unavailable on the other.
   - Each side has an optional club select, whose name and colors override the team.
   - "Usar estas alineaciones" (disabled until both sides are saved) → confirm → `applyLineupSquads`.
3. `components/squads/squad-editor.tsx`: add props for lineup mode (fixed team size, `excludePlayerIds`, `kind`, `matchId`, `side`) without changing the dream behavior.
4. Match detail header: show `ClubCrest` next to team names when `match_teams.club_id` is set. It may be null today, so render nothing then. Keep the change minimal.
5. Tests: `components/squads/squad-editor.test.tsx` gets lineup-mode additions (excluded players are hidden; the payload includes matchId/side), and an equipos-page toggle test if practical.
