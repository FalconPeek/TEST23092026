## Context
The M5 server layer is committed:
- **Badges:** catalog `badges(code, name_key, icon, category, sort)` with 15 codes, and `player_badges(player_id, badge_code, awarded_at, match_id, tournament_id, count)`; members of the group can read them.
- **Notification templates:** `lib/notifications/templates.ts` currently reads `es.notifications.<kind>` defensively and falls back to a built-in `FALLBACK_STRINGS` table, because the keys didn't exist yet. "UI strings only from messages/es.ts" means the fallback must go once the keys exist.
- **Share card:** `/api/og/card/[playerId]` renders a 1080×1350 PNG of the player's card. It's a public route by design, for sharing. It's being built by FATHER in parallel. If it doesn't exist yet when you start, set this task back to `todo`, note that in your report, and stop.

## Steps
1. `messages/es.ts`:
   - `notifications`: one entry per kind, `(params) => ({ title, body })`: match_scheduled({ groupName, scheduledAt }), report_pending(), rating_pending(), match_finalized({ team1Goals, team2Goals }), match_disputed({ reasonCount }), tournament_generated({ tournamentName }), tournament_match_ready({ round }), badge_awarded({ badgeName }), card_updated(). Wording in voseo: e.g. "Partido programado" / "{groupName} tiene un partido nuevo para el {scheduledAt}.", "Cargá el resultado", "Votá el partido", "Partido finalizado" / "Resultado final: X - Y.", "Partido en disputa", "Se armó el fixture" / "Ya está listo el cuadro de {tournamentName}.", "Nuevo partido de torneo" / "Tu partido de la ronda {round} ya está listo.", "¡Nueva insignia!" / "Ganaste la insignia {badgeName}.", "Tu carta cambió".
   - `badges`: `{ <code>: { name, description } }` for all 15: first_match "Primer partido", matches_10 "Habitué" (10 partidos), matches_50 "Veterano" (50), first_goal "Primer gol", hat_trick "Hat-trick" (3+ goles en un partido), goals_25 "Goleador" (25 goles), assist_king "Rey del pase" (**3+ asistencias en un partido**), mvp "Figura", mvp_5 "Figura recurrente" (5 veces MVP), clean_sheet "Valla invicta", clean_sheets_10 "Muralla" (10 vallas invictas), streak_3_wins "Racha ganadora" (3 victorias seguidas), tournament_champion "Campeón", scout_10 "Ojeador" (votaste a 10 compañeros distintos), gold_card "Carta dorada". Plus `badges.title` "Insignias", `badges.count` `(n) => "×{n}"`, `badges.none` "Todavía no ganó insignias."
   - `profile.share` "Compartir carta", `profile.downloadCard` "Descargar imagen", `profile.shareText` `(name) => "Mirá la carta de {name} en Picado"`.
2. `lib/notifications/templates.ts` (+ its test): read `es.notifications` directly and type-safely, and delete `FALLBACK_STRINGS` and the defensive `unknown` shape-check. `badgeAwardedPayload` must pass the badge's Spanish name (`es.badges[code].name`), not the raw code. Keep the exported builder names/signatures, except the badge one may take the code and resolve the name itself. Update its callers in `lib/server/*` only if a signature changes.
3. `components/player/badge-list.tsx` (server-safe): a grid of earned badges with a lucide icon by `badges.icon` (map the icon names to lucide components, with a fallback icon), the name, the description as a tooltip/sub-line, and `×n` for repeatables with count > 1. The empty state is `badges.none`.
4. `app/g/[groupId]/jugadores/[playerId]/page.tsx`: load `player_badges` joined with the `badges` catalog (sorted by `badges.sort`) and render a "Insignias" section.
5. `components/player/share-card-button.tsx` (`'use client'`). The profile page requires login, so link previews of it can't work. Share the public image instead:
   - Fetch `/api/og/card/[playerId]` as a Blob, turn it into a `File` (`carta-<name>.png`, `image/png`), and if `navigator.canShare?.({ files: [file] })`, call `navigator.share({ files: [file], title, text })`.
   - Otherwise, if `navigator.share` exists, share `{ title, text, url: <absolute /api/og/card/[playerId] URL> }`.
   - Otherwise copy that URL to the clipboard + toast.
   - Ignore `AbortError` (the user cancelled).
   - Include a secondary "Descargar imagen" link to `/api/og/card/[playerId]` (`download` attribute).
   - Show it on the profile under the card.
6. Tests: `components/player/badge-list.test.tsx` (count badge, empty state, unknown icon fallback), `components/player/share-card-button.test.tsx` (file share when canShare, url share fallback, clipboard fallback, AbortError ignored), and the updated `lib/notifications/templates.test.ts`.
