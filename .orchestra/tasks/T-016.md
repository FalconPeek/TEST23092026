## Context
The M4 schema and server layer are committed:
- **Tables:** `tournaments`, `tournament_entries`, `tournament_registrations`, `stages`, `stage_groups`, `tournament_matches`. All columns are in `lib/supabase/database.types.ts`, and members can select them via RLS.
- **Actions:** `lib/actions/tournaments.ts`: `createTournament({ groupId, name, format, teamSize, entryMode, settings })`, `updateTournament`, `setTournamentStatus`, …
- **Settings:** `lib/settings/tournament.ts` (`tournamentSettingsSchema`, `defaultTournamentSettings`, `parseTournamentSettings`). Keys: `seeding`, `points.{win,draw,loss,bye_counts_as_win}`, `tiebreakers[]`, `ko_draw_resolution`, `league.double_round_robin`, `single_elim.third_place`, `double_elim.grand_final_reset`, `groups_ko.{group_count,qualifiers_per_group,double_round_robin,third_place}`, `swiss.{rounds|null,tiebreakers[]}`.

The M4 RPCs raise these new codes, which currently fall back to the generic error:
- `PICADO_ALREADY_GENERATED` (a bracket already exists);
- `PICADO_KO_DRAW` (a knockout match tied with no pens/manual decision);
- `PICADO_NOT_EDITABLE` (downstream matches already started).

The T-006 placeholder `app/g/[groupId]/torneos/page.tsx` gets replaced.

## Steps
1. `messages/es.ts`:
   - `errors`: `tournamentAlreadyGenerated` "Este torneo ya tiene un fixture generado.", `koDrawNeedsDecision` "Este partido de eliminación terminó empatado: cargá los penales o decidí el ganador manualmente.", `resultNotEditable` "Ya no se puede editar este resultado: hay partidos siguientes en curso o finalizados."
   - `tournaments.*`: `title` "Torneos", `new` "Nuevo torneo", `empty` "Todavía no hay torneos.", `name` "Nombre", `format` "Formato", `formats.{league,single_elim,double_elim,groups_ko,swiss}` with a one-line help each (e.g. league "Liga: todos contra todos", single_elim "Eliminación directa", double_elim "Doble eliminación", groups_ko "Grupos + eliminatoria", swiss "Sistema suizo"), `entryMode` "Inscripción", `entryModes.teams` "Equipos armados por el organizador", `entryModes.individual` "Individual: los equipos se arman parejos automáticamente", `teamSize`, `status.{draft,registration,in_progress,finished}` ("Borrador", "Inscripción abierta", "En juego", "Terminado"), `created` "Torneo creado".
   - Settings labels, in Spanish: points win/draw/loss, third place, grand final reset, double round robin, group count, qualifiers per group, swiss rounds ("automático" when null), KO draw resolution options, seeding options (ovr "Por media", openskill "Por Impacto", manual, random "Sorteo"), and tiebreaker names.
2. `lib/actions/errors.ts` + test: map the 3 new codes.
3. `app/g/[groupId]/torneos/page.tsx`: the list of tournaments (name, format label, status badge, entries count). Admins get a "Nuevo torneo" button.
4. `app/g/[groupId]/torneos/nuevo/page.tsx` (admins only, else `notFound()`) + `components/tournament/create-tournament-form.tsx` (`'use client'`):
   - Fields: name, format as radio cards with help, entry mode, and team size (5/6/7/8/9/11, default from group settings).
   - A settings section that only shows the options relevant to the chosen format, plus points/tiebreakers/seeding/KO draw resolution under a collapsible "Reglas".
   - The tiebreaker order is edited with up/down buttons (no drag library).
   - Validate with `tournamentSettingsSchema.safeParse`, submit `createTournament`, then go to `/g/[id]/torneos/[tournamentId]`.
5. Tests: `components/tournament/create-tournament-form.test.tsx` (format-specific fields show/hide; the tiebreaker reorder; invalid settings block submit; submit payload), plus the errors test additions.
