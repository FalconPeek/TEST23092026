## Context
Product decision (user): a match whose score is agreed but whose goals weren't all reported by scorer now **finalizes** (it's no longer disputed). The missing goals stay unattributed, and a group admin can assign them later.
- Server side is done: `amendMatchStats({ groupId, matchId, stats: [{ subjectPlayerId, goals?, assists?, ownGoals?, saves? }] })` in `lib/actions/matches.ts`. Only the keys you send change.
- The RPC `amend_match_stats` enforces: admin only, finalized only, per side Σ goals + opponent own goals ≤ score, and assists ≤ score − opponent own goals. It raises `PICADO_VALIDATION` otherwise, which maps to the generic validation copy. Every change is audited, and newly earned badges are awarded.
- The finalized result view is `components/match/match-result.tsx` (T-015). The stat row UI is `components/match/stat-row.tsx`.

## Steps
1. `messages/es.ts`: add `match.*`:
   - `unattributed` `(n) => n === 1 ? "1 gol sin autor" : "{n} goles sin autor"`;
   - `amendTitle` "Asignar goles", `amendHelp` "Asigná los goles que nadie cargó, o corregí asistencias y atajadas. El resultado no cambia.", `amendSave` "Guardar cambios", `amended` "Estadísticas actualizadas", `amendOverScore` `(team) => "{team} no puede tener más goles que su resultado"`.
2. Pure helper `lib/match/amend.ts`:
   - `unattributedGoals(score, statsBySide)`: per side, `score − Σ goals − opponent Σ own_goals` (never negative).
   - `validateAmendment(...)`: the same two caps as the SQL, returning per-side errors.
   - `changedRows(initial, edited)`: only rows with a changed field, and only the changed keys.
   - Tests in `lib/match/amend.test.ts`.
3. `components/match/match-result.tsx`: under each team's stats table, when that side has unattributed goals, show a muted "N goles sin autor" line.
4. `components/match/amend-stats-form.tsx` (`'use client'`, admin only, status `finalized`):
   - A collapsible "Asignar goles" section below the result.
   - One `StatRow` per team player grouped by team, prefilled from `match_stats`.
   - A live per-team counter "Sin autor: N" and the `amendOverScore` error, which blocks submit while over the cap.
   - Submit sends only `changedRows` → `amendMatchStats` → toast `match.amended` + `router.refresh()`.
   - All controls ≥44px.
5. `app/g/[groupId]/partidos/[matchId]/page.tsx`: render the form for admins when finalized, passing the score from `match_results` and the rows from `match_stats`.
6. Tests: `components/match/amend-stats-form.test.tsx` (sends only changed keys; blocks when over the score; hidden for non-admins is handled by the page, so just test that the form renders the counter), plus the `lib/match/amend.test.ts` from step 2.
