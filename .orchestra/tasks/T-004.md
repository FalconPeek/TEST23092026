## Context
The player card is the heart of Picado's UI: an EA FC 26 Ultimate-Team-style card. It is a pure presentational component driven by props (the rating engine produces the data later). Tier tokens (`--tier-<tier>-from/-to/-fg/-accent` for bronze/silver/gold/special/provisional) and the `.fut-shield` clip-path utility exist in `app/globals.css` (T-002). Labels come from `es.card.*`, `es.positions`, `es.foot` in `messages/es.ts` (T-001).

## Steps
1. `components/card/player-card.tsx` — named export `PlayerCard` and exported props types:
   ```ts
   export type CardTier = "bronze" | "silver" | "gold" | "special";
   export type OutfieldFace = { pac: number; sho: number; pas: number; dri: number; def: number; phy: number };
   export type GkFace = { div: number; han: number; kic: number; ref: number; spd: number; pos: number };
   export type PlayStyleBadge = { code: string; label: string; plus: boolean };
   export type PlayerCardProps = {
     name: string;
     avatarUrl?: string | null;
     ovr: number;                 // 1–99
     position: PositionCode;      // one of the 15 keys of es.positions (export `type PositionCode = keyof typeof es.positions`)
     tier: CardTier;
     isProvisional: boolean;      // renders with the provisional (grey) palette + hint, keeps the tier name hidden
     face: { kind: "outfield"; stats: OutfieldFace } | { kind: "gk"; stats: GkFace };
     weakFoot: 1 | 2 | 3 | 4 | 5;
     skillMoves: 1 | 2 | 3 | 4 | 5;
     preferredFoot?: "left" | "right" | "both";
     playStyles?: PlayStyleBadge[]; // show at most 3 on the card
     size?: "sm" | "md" | "lg";    // sm ≈ 120px wide (lists), md ≈ 200px (default), lg ≈ 300px (profile)
     className?: string;
   };
   ```
   Layout (like an FC card): shield shape (`fut-shield`) with a vertical gradient from the tier tokens; top-left column: big OVR, position abbreviation under it, small PlayStyle icons column (use short text/lucide icons; `+` variants get a highlighted ring); top-right: avatar (`components/ui/avatar` with initials fallback); the name centered in a band; bottom: the 6 face stats in two columns of three (`value LABEL`, labels from `es.card.faceStats` or `es.card.gkStats`); footer row with ★ weak foot / ★ skill moves. Must be legible at every size (scale typography with the size variant). Special tier gets a subtle animated sheen (CSS only, respect `prefers-reduced-motion`). Provisional shows a small badge with `es.card.tiers.provisional` and a `title`/tooltip with `es.card.provisionalHint`.
   Accessibility: the root is a `<figure>` with an `aria-label` like `${name}, ${ovr} ${positionName}` and keep stats as real text.
   Server-component compatible (no hooks, no `'use client'`).
2. `components/card/player-card.test.tsx`: renders outfield and GK variants (correct labels RIT/TIR/... vs EST/MAN/...), shows OVR and position, caps PlayStyles to 3, provisional renders the provisional badge.
3. `app/dev/cards/page.tsx`: a preview gallery showing ~8 sample cards covering every tier, provisional, a GK, all three sizes, a long name, missing avatar, and 0/3 PlayStyles. Guard it so it 404s in production: `if (process.env.NODE_ENV === "production") notFound();`.
