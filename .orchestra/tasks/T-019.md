## Context
Standings are not stored; they're computed on read. In an RSC:

```ts
computeStandings(createSupabaseTournamentRepo(await createClient()), tournamentId)
```

(from `lib/server/tournaments.ts` / `lib/server/tournament-repo.ts`). This returns `{ stageId, groupId, rows: StandingsRow[] }[]`, where `StandingsRow` has `entryId, played, wins, draws, losses, goalsFor, goalsAgainst, goalDiff, points, buchholz, sonnebornBerger, lot, rank` (`lib/brackets/types.ts`).
- The tiebreaker order comes from the tournament settings.
- groups_ko: `settings.groups_ko.qualifiers_per_group` rows per group qualify.
- swiss: `buchholz`/`sonnebornBerger` are shown, and rounds are appended automatically as they complete.

Fixtures are `tournament_matches` rows ordered by round/number. The admin result menu and the realtime component come from T-018 (`match-admin-menu.tsx`, `tournament-realtime.tsx`); reuse both.

## Steps
1. `messages/es.ts`: add `standings.*`:
   - Column abbreviations with `title` tooltips: Pos, PJ, G, E, P, GF, GC, DG, Pts, Buch., S-B.
   - `qualified` "Clasifica", `group` `(label) => "Grupo {label}"`, `matchday` `(n) => "Fecha {n}"`, `swissRound` `(n) => "Ronda {n}"`, `noMatches` "Todavía no hay partidos."
2. `components/tournament/standings-table.tsx` (server-safe): a compact table at 375px. It shows Pos/Equipo/PJ/DG/Pts by default, with extra columns (G/E/P/GF/GC and, for swiss, Buch./S-B) from `sm:`. Qualified rows get a left accent bar. A "lot" marker appears when a sorteo decided the position.
3. `components/tournament/fixtures-list.tsx` (server-safe): matches grouped by round (league matchday, swiss round, groups by group label then round). Each row shows home/away, score or status, a link to the real match, and the admin menu (T-018) when admin.
4. `app/g/[groupId]/torneos/[tournamentId]/tabla/page.tsx`: standings per group (groups_ko) or a single table (league/swiss), plus realtime.
5. `app/g/[groupId]/torneos/[tournamentId]/fechas/page.tsx`: the fixtures list for all formats, plus realtime.
6. Tests: `components/tournament/standings-table.test.tsx` (qualified highlight, swiss columns only for swiss, the lot marker) and `components/tournament/fixtures-list.test.tsx` (grouping by round/group; bye rows).
