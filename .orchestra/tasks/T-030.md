## Context
FUT-style squads (M7). Everything below is committed. Nothing about ratings is computed ad hoc; use the pure engine.
- **Engine** `lib/squads`:
  - `FORMATIONS`, `formationsFor(teamSize)`, `findFormation(teamSize, code)`, `defaultFormation(teamSize)`. Each formation slot has `{ slot, position, x, y }`, with x/y in % of the pitch (y = 0 is the attacking end).
  - `teamRating(formation, assignment)` and `squadChemistry(formation, assignment, shared, settings)`.
  - `buildSquadContext(...)` / `buildSquadView(squad, context, settings)` → `{ formation, slots: [{ slot, position, x, y, player: { id, name, avatarUrl, ovr, tier, provisional, chemistry } | null }], rating, chemistry }`.
- **Server loader** `lib/server/squad-context.ts`: `loadSquadContext(supabase, groupId) → { context, settings }`. Call it in RSC with the session client, and pass the serializable parts to the client editor (convert Maps to arrays/objects).
- **Actions** (`lib/actions/squads.ts`):
  - `saveSquad({ squadId|null, groupId, kind: "dream", name, teamSize, formation, slots: [{ slot, playerId }], clubId|null, matchId: null, side: null }) → { squadId }`. Positions come from the formation.
  - `deleteSquad`, `setSquadPublished({ groupId, squadId, published })`, `likeSquad({ groupId, squadId, like })` (you can't like your own squad: `PICADO_SELF_VOTE`).
- **Tables:** `squads(id, group_id, owner_player_id, kind, name, team_size, formation, club_id, published, published_at, …)`, `squad_slots(squad_id, slot, position, player_id)`, `squad_likes(squad_id, player_id)`. RLS: my own squads, plus published squads and lineup squads of my groups.
- **RPC** `get_featured_squad(p_group_id, p_window_days)` → `[{ squad_id, likes }]`. The window comes from group settings `squads.featured_window_days`.
- **Share image:** `/api/og/squad/[squadId]` (published squads only).

## Steps
1. `messages/es.ts` (`squads` namespace, keep the existing keys):
   - `title` "Plantillas", `mine` "Mis plantillas", `community` "Del grupo", `new` "Nueva plantilla", `name` "Nombre de la plantilla", `teamSize`, `formation` "Formación", `rating` "Media", `chemistry` "Química", `pickPlayer` "Elegí un jugador", `emptySlot` "Vacío", `outOfPosition` "Fuera de posición";
   - `publish` "Publicar", `unpublish` "Dejar de publicar", `published` "Publicada", `like` "Me gusta", `likes` `(n) => …`, `share` "Compartir", `featured` "Equipo de la semana", `noFeatured` "Todavía no hay equipo de la semana.", `saved` "Plantilla guardada", `deleted` "Plantilla eliminada", `deleteConfirm`, `by` `(name) => "de {name}"`;
   - chemistry help: "Química: posición (principal +2 / alternativa +1), +1 si jugaron juntos {n} partidos, +1 por club".
2. `components/squads/pitch.tsx` (server-safe presentational): a green pitch (aspect 4:5, max-w ~420px) with slot markers absolutely positioned from x/y.
   - Each marker is a mini card: OVR, position, first name, a tier background (reuse the tier tokens), and chemistry dots (0–3).
   - Empty slots show "+" with the position.
   - Markers are ≥44px tap targets. When interactive, it takes an `onSlotClick` via a client wrapper.
3. `components/squads/squad-editor.tsx` (`'use client'`):
   - name, team size select, formation chips from `formationsFor`;
   - the pitch: tap a slot → a bottom sheet with group players sorted by OVR at that slot's position (show OVR at position, and whether it's their primary/alt/other position), excluding players already placed; there's also a "Quitar" option;
   - live rating and chemistry via the engine on every change;
   - optional club select (shows its crest);
   - Save → `saveSquad`.
   - Changing the formation keeps players whose slot index still exists.
4. Pages:
   - `app/g/[groupId]/plantillas/page.tsx`: the "Equipo de la semana" card (featured squad on a mini pitch + likes), "Mis plantillas" (list with rating/chemistry, published badge), "Del grupo" (published squads by others with a like toggle and like count), and a "Nueva plantilla" button.
   - `app/g/[groupId]/plantillas/nueva/page.tsx` and `app/g/[groupId]/plantillas/[squadId]/page.tsx`. The owner gets the editor, publish/unpublish, delete, and share when published. Others get a read-only pitch + like.
   - Share uses the Web Share API with the PNG from `/api/og/squad/[id]` as a file when `navigator.canShare({ files })`, else the URL, else the clipboard (same pattern as the card share button from T-023; reuse its helper if extracted).
5. Entry point: a "Plantillas" link on the group home, and a link from the player profile ("Armá tu plantilla").
6. Pure helper `lib/squads/editor-state.ts` (set/clear slot, change formation keeping valid slots, candidates for a slot sorted by slot OVR), with tests. Also add `components/squads/squad-editor.test.tsx` (the rating/chemistry update when placing a player; a player can't be placed twice; save payload has no positions).

## Acceptance criteria
- Rating and chemistry always come from `lib/squads` (the same numbers the share image shows).
- Other users' unpublished squads are never shown (RLS enforces it, and don't try to fetch them).
- Works one-handed at 375px: the pitch fits the width and the player picker is a bottom sheet.
