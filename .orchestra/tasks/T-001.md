## Context
All UI copy lives in `messages/es.ts` (Spanish, Argentina, **voseo**: "Entrá", "Votá", "Cargá"). No next-intl. All dates/numbers are formatted in es-AR, timezone `America/Argentina/Buenos_Aires`, through helpers in `lib/format.ts`. These two files are imported by almost every later UI task, so keep them simple, typed and stable.

## Steps
1. Create `messages/es.ts` exporting `export const es = { ... } as const;` and `export type Messages = typeof es;`. Group by feature namespace. Include at least:
   - `app`: `name: "Picado"`, `tagline` (short, e.g. "Tu fútbol con amigos, con cartas, torneos y estadísticas").
   - `common`: `save`, `cancel`, `confirm`, `delete`, `edit`, `back`, `loading`, `error` ("Algo salió mal. Probá de nuevo."), `retry`, `close`, `continue`, `yes`, `no`.
   - `nav`: `home` ("Inicio"), `matches` ("Partidos"), `tournaments` ("Torneos"), `rankings` ("Rankings"), `me` ("Yo"), `settings` ("Ajustes").
   - `auth`: `title` ("Entrá a Picado"), `withGoogle` ("Continuar con Google"), `withDiscord` ("Continuar con Discord"), `orEmail` ("o con tu email"), `emailLabel`, `emailPlaceholder` ("vos@ejemplo.com"), `passwordLabel`, `sendMagicLink` ("Mandame un link mágico"), `magicLinkSent` ("Revisá tu email: te mandamos un link para entrar."), `signInWithPassword` ("Entrar con contraseña"), `magicLinkTab` ("Link mágico"), `passwordTab` ("Contraseña"), `signOut` ("Cerrar sesión"), `invalidCredentials` ("Email o contraseña incorrectos."), `invalidEmail` ("Ingresá un email válido."), `codeErrorTitle` ("No pudimos iniciar tu sesión"), `codeErrorBody` ("El link expiró o ya se usó.    - `landing`: `cta` ("Empezá ahora"), `features` — an array of 3–4 `{ title, body }` (cartas estilo FC votadas por tus amigos; torneos con llaves automáticas; estadísticas y rankings después de cada partido; calificaciones post-partido).
   - `card`: `tiers` object with keys `bronze`/`silver`/`gold`/`special`/`provisional` → "Bronce"/"Plata"/"Oro"/"Especial"/"Provisoria"; `faceStats` outfield keys `pac, sho, pas, dri, def, phy` → "RIT","TIR","PAS","REG","DEF","FIS"; `gkStats` keys `div, han, kic, ref, spd, pos` → "EST","MAN","SAQ","REF","VEL","COL"; `weakFoot` ("Pierna mala"), `skillMoves` ("Filigranas"), `provisionalHint` ("Faltan votos para una carta definitiva").
   - `positions`: all 15 keys `POR, LI, DFC, LD, CAI, CAD, MCD, MC, MCO, MI, MD, EI, ED, SD, DC` → full Spanish names (Portero, Lateral izquierdo, Defensa central, Lateral derecho, Carrilero izquierdo, Carrilero derecho, Mediocentro defensivo, Mediocentro, Mediapunta, Medio izquierdo, Medio derecho, Extremo izquierdo, Extremo derecho, Segundo delantero, Delantero centro).

   - `foot`: `left` ("Zurdo"), `right` ("Diestro"), `both` ("Ambidiestro").
   - `roles`: `owner` ("Dueño"), `admin` ("Admin"), `member` ("Jugador"), `spectator` ("Espectador").
2. Create `lib/format.ts` with named exports, all using `Intl` with locale `es-AR` and timeZone `America/Argentina/Buenos_Aires` (export both as constants `LOCALE`, `TIME_ZONE`). Cache the `Intl.DateTimeFormat`/`NumberFormat` instances at module level.
   - `formatDate(d: Date | string): string` → "23/9/2026" (options `{ day: "numeric", month: "numeric", year: "numeric" }`).
   - `formatDateLong(d)` → e.g. "martes 23 de septiembre" (`weekday: "long", day: "numeric", month: "long"`).
   - `formatTime(d)` → "20:30" (24h, `hour: "2-digit", minute: "2-digit", hourCycle: "h23"`).
   - `formatDateTime(d)` → `${formatDateLong(d)}, ${formatTime(d)}`.
   - `formatRelative(d, now: Date = new Date())` → Spanish relative time via `Intl.RelativeTimeFormat("es-AR", { numeric: "auto" })` picking the largest sensible unit (seconds < 60 → minutes → hours → days → weeks → months → years), e.g. "hace 3 horas", "en 2 días", "ayer", "mañana".
   - `formatNumber(n: number, maxFractionDigits = 0)` → es-AR grouping ("1.234").
   - `formatDecimal(n: number, digits = 1)` → exactly `digits` fraction digits ("7,5").
   - `formatPercent(ratio: number)` → "40 %" style via `style: "percent"`, 0 fraction digits.
   - Accept ISO strings as well as Date for date helpers; throw `RangeError` on an invalid date.
3. Create `lib/format.test.ts` with tests for every helper, using fixed instants and asserting the Buenos Aires timezone is applied (e.g. `2026-09-24T01:30:00Z` is still the 23rd, 22:30 in Buenos Aires). Normalize non-breaking spaces (U+00A0 and U+202F) in assertions if Intl emits them. Add a test that `es` has exactly 15 position keys and 34 attribute keys.
