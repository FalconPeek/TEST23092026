## Context
`/g/[groupId]/ajustes` is the group management page. Everyone sees it (members list + "Salir del grupo"); admin-only sections are rendered only for owner/admin (the RPCs enforce permissions anyway — UI hiding is cosmetic). Read my role from `group_members` (row where `user_id` = me). RLS: members see all `group_members` and `players` of their group; only admins can select `invites`. Member display names/avatars come from `profiles` (visible to users sharing a group) or the member's `players` row. Actions in `lib/actions/groups.ts`.

Role rules (enforced in SQL, mirror them in the UI so impossible actions aren't offered): only the owner can make/unmake admins and create admin invites; admins can switch member↔spectator and remove members/spectators; only the owner can remove admins; nobody changes the owner's role except via "Transferir grupo" (owner only, target must be a member); the owner can't leave until transferring.
