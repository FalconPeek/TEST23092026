## Context
Friendlies (and later tournament matches) live in these tables:
- `matches(id, group_id, tournament_match_id, kind, team_size, scheduled_at, played_at, venue, status scheduled|reporting|disputed|pending_finalize|finalized|cancelled, report_deadline, rating_deadline, created_by)`
- `match_teams(match_id, side 1|2, name, color)`
- `match_participants(match_id, player_id, team_id nullable, role player|spectator, position)`

Admins create matches and set lineups, via the actions in `lib/actions/matches.ts` (T-010): `createMatch`, `setMatchLineup`, `startReporting`, `cancelMatch`.

Team balancing: `balanceTeams(players: {id, mu, ovr, isGk?}[], 2, rng)` from `lib/rating/balance.ts`. Get `mu` from `openskill_ratings(player_id, mu, sigma, ordinal, matches_played)`, defaulting to 25 when there's no row. Get `ovr` from `player_cards.ovr`, defaulting to 60. `isGk` = primary_position `POR`. Use `seededRng` from `lib/brackets` with `Date.now()` so "Rearmar" gives a new draw. The T-006 placeholder `app/g/[groupId]/partidos/page.tsx` gets replaced.

## Steps
1. `messages/es.ts`: add `matches.*`:
   - `title` "Partidos", `upcoming` "Próximos", `recent` "Jugados", `new` "Nuevo partido", `when` "Fecha y hora", `venue` "Cancha", `teamSize` "Jugadores por equipo", `teamSizeOption` `(n) => "Fútbol {n}"`, `lineup` "Equipos", `team1Default` "Blancos", `team2Default` "Negros", `bench` "Sin asignar", `spectators` "Espectadores", `balance` "Armar parejos", `rebalance` "Rearmar", `strength` `(mu, ovr) => …`, `saveLineup` "Guardar equipos", `startReporting` "Terminó el partido", `cancel` "Cancelar partido", `cancelConfirm`, `empty` "Todavía no hay partidos."
   - `status.*` for every status (e.g. reporting "Cargando resultados", disputed "En disputa", pending_finalize "Por cerrar", finalized "Finalizado", cancelled "Cancelado", scheduled "Programado").
2. `app/g/[groupId]/partidos/page.tsx`: upcoming (scheduled, ordered by date) and recent (the rest, most recent first, limit 30) lists. Each item is a card with the date (`lib/format.ts`), venue, status badge, team names + score when `match_results` exists, and a link to `/g/[id]/partidos/[matchId]`. There's a "Nuevo partido" button for admins.
3. `app/g/[groupId]/partidos/nuevo/page.tsx` + `components/match/create-match-form.tsx` (`'use client'`):
   - Fields: datetime-local input (interpreted as America/Argentina/Buenos_Aires → ISO; add a `toArgentinaIso(localValue)` helper to `lib/format.ts` with tests), venue, and team size select (5/6/7/8/9/11, default from group settings `default_team_size`).
   - On success → `/g/[id]/partidos/[matchId]/equipos`.
   - Non-admins → `notFound()`.
4. `app/g/[groupId]/partidos/[matchId]/equipos/page.tsx` + `components/match/lineup-editor.tsx` (`'use client'`):
   - Admin only; status must be `scheduled`.
   - All active group players (members and guests; spectator-role members only as spectators) start in "Sin asignar", or prefilled from existing participants.
   - Tap a player to cycle through Equipo 1 → Equipo 2 → Espectador → Sin asignar. Also: an editable team name + color per team, an optional position select per player, and a live strength summary (Σμ, avg OVR) per team with a count warning when a team ≠ team_size.
   - "Armar parejos" balances the selected (non-spectator) players.
   - "Guardar equipos" calls `setMatchLineup`.
   - Also "Terminó el partido" (`startReporting`, confirm) and "Cancelar partido" (confirm).
   - Pure helper `lib/match/lineup.ts` for the state transitions + balance mapping, with tests.
5. Tests:
   - `lib/match/lineup.test.ts`: the cycle order; spectator-role members can't join a team; balance splits the selected players only; position kept on team change.
   - `lib/format.test.ts` additions for `toArgentinaIso`.
   - `components/match/create-match-form.test.tsx`.
