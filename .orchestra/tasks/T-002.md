## Context
Picado is dark-theme-first and mobile-first (design at 375px width). The scaffold still has the create-next-app layout (`lang="en"`, "Create Next App" metadata) and the default shadcn neutral light theme in `app/globals.css`. Tailwind 4 is configured CSS-first in `app/globals.css` (no tailwind.config.js). shadcn components live in `components/ui` (includes `sonner.tsx`). `next-themes` is installed. Read `node_modules/next/dist/docs/` for anything Next-16-specific (metadata, viewport, fonts).

## Steps
1. `app/globals.css`:
   - Make the **dark** palette the default look: keep the `:root` light vars but the app forces dark (see layout). Tune the `.dark` palette to a pitch-at-night feel: near-black green-tinted background, primary = vivid pitch green (e.g. `oklch(0.72 0.19 150)`) with dark foreground on primary, accent/ring consistent with it. Keep contrast AA for text.
   - Add FUT card tier tokens (both as CSS vars and exposed in `@theme inline` as colors so `bg-tier-gold-from` etc. work): for each tier `bronze`, `silver`, `gold`, `special`, `provisional` define `--tier-<t>-from`, `--tier-<t>-to` (gradient stops), `--tier-<t>-fg` (text color on the card) and `--tier-<t>-accent` (lines/borders). Bronze = copper/brown, silver = cool grey-white, gold = rich yellow-gold, special = deep purple→magenta/teal (TOTW-ish), provisional = desaturated grey.
   - Add a `.fut-shield` utility class (via `@utility fut-shield { ... }`) implementing the card shield shape with `clip-path: polygon(...)` (flat top with cut corners, pointed/tapered bottom like an FC card).
2. `app/layout.tsx`:
   - `<html lang="es-AR" className="dark ..." suppressHydrationWarning>`; keep Geist fonts.
   - `metadata`: title template `{ default: "Picado", template: "%s · Picado" }`, description from `es.app.tagline`, `applicationName: "Picado"`.
   - Export `viewport` with `themeColor` matching the dark background and `width: "device-width", initialScale: 1, viewportFit: "cover"`.
   - Render `<Toaster />` from `@/components/ui/sonner` (position top-center, `richColors`). If `components/ui/sonner.tsx` depends on `next-themes`' `useTheme`, wrap children in a small client `ThemeProvider` (`components/theme-provider.tsx`, `attribute="class"`, `defaultTheme="dark"`, `enableSystem={false}`) so the toaster resolves dark.
   - Body: `min-h-dvh bg-background text-foreground` plus safe-area padding friendly classes.
3. `app/page.tsx` (public landing, Server Component): hero with app name, tagline, CTA button (shadcn `Button` rendered as a `Link` to `/login`, label `es.landing.cta`), and the `es.landing.features` list as simple cards. Mobile-first, looks good at 375px, centered max-w on larger screens. No images required; you may use lucide-react icons. All copy from `messages/es.ts`.
